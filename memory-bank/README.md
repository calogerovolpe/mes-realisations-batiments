# Mes réalisations bâtiment — CAO / DAO

Portfolio statique axé sur le dessin technique : planches CAO/DAO réalisées sous
AutoCAD, modèles de chiffrage Excel, parcours de dessinateur projeteur.

Site publié via GitHub Pages :
https://calogerovolpe.github.io/mes-realisations-batiments/

## Structure
- Pages HTML à plat à la racine
- assets/css/style.css — feuille de style unique (thème « plan technique »)
- assets/css/print.css — feuille d'impression
- assets/img/ — planches du portfolio et captures
- memory-bank/ — état d'avancement du projet
- docs/ — documents de référence, locaux, jamais publiés (voir .gitignore)

## Contenu
Travaux réalisés à titre personnel et lors d'un stage auprès d'un architecte
indépendant. Les documents liés à la collectivité territoriale sont confidentiels
et ne sont pas publiés.

## Publication
Dépôt public, branche main, dossier / (root). Toute modification est poussée
avant d'être considérée comme terminée.
