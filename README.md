# Volpe Calogero — Dessinateur projeteur CAO / DAO

Portfolio statique axé sur le dessin technique : planches CAO/DAO réalisées sous
AutoCAD, modèles de chiffrage Excel, parcours centré sur le dessin technique.

Site publié via GitHub Pages :
`https://calogerovolpe.github.io/mes-realisations-batiments/`

## Technique
HTML5 + CSS, JavaScript vanilla en amélioration progressive. Aucun framework,
aucun build, aucune dépendance externe, aucune police téléchargée.

## Structure
- Pages HTML à plat à la racine
- `assets/css/style.css` — feuille de style unique (thème « plan technique »)
- `assets/css/print.css` — feuille d'impression
- `assets/img/` — planches du portfolio, captures et extraits
- `assets/fichiers/` — CV au format PDF (seul document téléchargeable)
- `assets/js/` — point d'entrée `main.js` (defer) + modules
- `memory-bank/` — état d'avancement du projet

## Contenu
Travaux réalisés à titre personnel et lors d'un stage auprès d'un architecte
indépendant. Les documents liés à la collectivité territoriale (patrimoine bâti
municipal) sont confidentiels et ne sont pas publiés. Les planches présentées ne
comportent ni adresse ni donnée nominative.
